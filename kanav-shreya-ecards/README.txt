Kanav & Shreya Wedding Invitation: three e-cards
=================================================

shreyaweds    https://shreyaweds.kanavchopra.com    all eight functions
shreyawedss   https://shreyawedss.kanavchopra.com   Mata Ki Chowki, Shagun, Sufi Night / Cocktail, Saant, Sehra Bandi, Baraat & Reception
shreyawedsss  https://shreyawedsss.kanavchopra.com  Mata Ki Chowki, Mehendi & Sangeet, Saant, Sehra Bandi, Baraat & Reception

Each folder is a complete site in one file (index.html) and is deployed
as its own Vercel project:

  Root Directory    kanav-shreya-ecards/<folder>
  Framework Preset  Other (no build command, no output directory)
  Domain            <folder>.kanavchopra.com

Each subdomain needs a CNAME record at Namecheap (Advanced DNS):
Host <folder>, Value cname.vercel-dns.com, or the target Vercel shows.

Keep each file named index.html.
